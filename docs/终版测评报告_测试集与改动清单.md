### D. 已知边界（如实交底）

2. 扫描版 PDF / 手写体识别效果有限（已在落地页声明）
3. LLM 日额度计数在内存中，服务重启清零（防脚本足够，精确计费需入库）
4. SRS / 批量勾选删除 / 移动端滑动标记：已排期未实现
